_CoffeeTrendViewer 要件定義書_


## 1. プロジェクト概要
### サービスコンセプト・設計方針

CoffeeTrendViewerは、コーヒー愛好家同士の知識・経験・嗜好に関する情報共有を目的とするサービスである。コーヒー豆の購入情報や味覚の嗜好を収集し、日本国内の地域ごとのコーヒー嗜好の傾向を地図上に可視化するローカルWebアプリケーションである。

一般的なSNSのようなユーザー間の交流や承認を中心とする設計は採用せず、コーヒーに関する情報の蓄積・閲覧・検索・地域別分析を中心とする。

### 基本方針

- ユーザー同士のフォロー機能、DM、ランキングなどは設けない。
- いいね数やフォロワー数など、承認や競争を促す指標を設けない。
- ユーザーは任意の表示名を使用できる。
- 氏名、電話番号、正確な住所など、サービス目的に不要な個人情報は原則収集しない。
- 投稿データは地域別統計や情報検索に活用する。
- 個人を特定し得る情報の公開を避け、少数データの統計表示を抑制する。
- 投稿者自身が投稿を編集・削除できる仕組みを検討する。
- 統計情報には集計期間、対象件数、計算方法を明示する。

### サービスが提供する価値

- ユーザー同士が直接的な関係を構築しなくても、他者のコーヒーに関する知識や経験に触れられる環境を提供する。
- 競争や承認欲求ではなく、コーヒーへの関心と知的好奇心を通じた、穏やかな情報共有を目指す。
- MVP（Minimum Viable Product）では、コーヒー情報の登録、地域別データの集計、日本地図上への可視化という基本的なワークフローの実現を目指す。


## 2. プロジェクトの目的

- コーヒー豆の情報と味覚の嗜好を登録できるようにする。
- 登録データをローカルのSQLiteデータベースに保存する。
- 地域ごとのコーヒーの嗜好を集計する。
- 日本地図上に地域別の嗜好傾向を可視化する。
- 可視化の根拠となる統計情報を確認できるようにする。


## 3. 動作環境

- OS：Windows
- Runtime：.NET 10
- Backend：ASP.NET Core
- Database：SQLite
- Frontend：HTML / CSS / JavaScript
- アクセス方法：localhost経由でブラウザからアクセス

## 4. 機能要件

### FR-01：コーヒー情報の登録

ユーザーは購入したコーヒー豆の情報を登録できる。

登録候補項目：

- コーヒー名
- 生産国
- 生産地域
- 味覚の特徴
- 焙煎度
- 購入日
- テイスティングノート

最終的な登録項目はデータベース設計時に決定する。

### FR-02：データの永続化

- 登録データをSQLiteに保存する。
- アプリケーション再起動後もデータを保持する。
- 保存前に基本的な入力検証を行う。

### FR-03：地域別データ集計

- 登録されたコーヒーの嗜好を地域別に集計する。
- 味覚属性の出現頻度または構成比を計算する。
- データ数が不十分な地域については統計情報の表示を抑制する。

地域集計の単位

- MVPでは日本全国47都道府県を集計単位とする。
- 市区町村単位の集計はMVPの対象外とする。
- 将来的に市区町村単位へ拡張できる設計を考慮する。

### FR-04：地図表示

- 日本地図を表示する。
- 色のグラデーションによって地域ごとのコーヒー嗜好を可視化する。
- 地域ごとの傾向の違いを確認できるようにする。
- 地域を選択すると、その地域の統計情報を表示する。

### FR-05：統計情報の表示

以下の情報を必要に応じて表示する。

- 投稿件数
- 集計対象期間
- 主な味覚の特徴
- 統計計算方法

## 5. プライバシー要件

- 可能な範囲で投稿者を特定する情報とコーヒー投稿データを分離する。
- 個々の投稿記録を地域別統計画面から公開しない。
- 投稿件数が不十分な地域の統計情報を抑制する。
- 正確な住所や個人の詳細な位置情報を公開しない。

本MVPはローカルアプリケーションであり、これらの対策は匿名性を保証するものではない。

## 6. 非機能要件

- Windows上でローカル実行できること。
- 一般的なWebブラウザから利用できること。
- アプリケーションの起動終了をまたいでデータが保持されること。
- 保守性と責務分離を考慮した構造にすること。
- 可能な範囲で外部サービスへの依存を抑えること。

## 7. MVPの対象外

- パブリッククラウドへのデプロイ
- 複数ユーザーによる同時アクセス
- ユーザー認証・アカウント管理
- SNS機能
- 全国規模のリアルタイム統計更新
- AIによる味覚分析
- 商用向け分析ダッシュボード

## 8. MVPの完了条件

以下をすべて満たした場合、MVP完成とする。

1. アプリケーションをローカルで起動できる。
2. コーヒー豆の情報を登録できる。
3. 登録情報がSQLiteに永続化される。
4. 保存されたデータから地域別統計を計算できる。
5. 日本地図上に地域別の嗜好傾向を表示できる。
6. 統計情報を確認できる。
7. 基本的な入力検証とプライバシー対策が実装されている。
